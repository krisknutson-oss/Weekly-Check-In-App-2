# The Weekly Ledger — Classroom Progress Tracker

Turn weekly lesson slides into 20-question check-in quizzes with student PIN logins, detailed class analytics, and readiness tracking for culminating unit activities.

## Deploying to GitHub Pages

1. In your GitHub repository, navigate to **Settings** > **Pages** (in the left sidebar).
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Go to the **Actions** tab to watch the automated deployment build. Once finished with a green checkmark, your site will be live at `https://<username>.github.io/<repo-name>/`.
